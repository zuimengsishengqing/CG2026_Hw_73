**HW6 ARAP 修复总结**
- **位置**: [source/Editor/geometry_nodes/hw6_arap.cpp](source/Editor/geometry_nodes/hw6_arap.cpp)

- **问题一（能量恒为0）**: 能量计算时大量/全部三角形被跳过或 J 与 L 不一致，导致 current_energy 为 0。
  - **原因**: 局部阶段使用的协方差/SVD 与全局/能量计算使用的雅可比定义不一致；同时全局方程右端项缺失了边界顶点的 `cot * u_j` 项，方程不完整。
  - **修复**: 局部阶段统一为论文形式：J = [u1-u0, u2-u0] * [x1-x0, x2-x0]^{-1}，对 J 做 SVD 得到 L。全局右端项加入邻居为边界时的 `cot * uv` 贡献。

- **问题二（余切权重映射错误）**: 之前将三角形的 `cot0/cot1/cot2` 与边的对应关系混淆，导致拉普拉斯矩阵系数错误。
  - **修复**: 简化并规范映射：对边 (i,j) 在每个相邻三角形中，取该三角形中不属于 (i,j) 的顶点对应的 cot 值作为贡献（即“对边的对角余切”）。

- **问题三（数值/退化保护不足）**:
  - **修复**: 对局部 X 矩阵行列式做阈值检测（|det| < EPSILON 则退化，L 取单位矩阵）；对 J/L 做 `allFinite()` 检查并回退到单位矩阵，避免 NaN/Inf 传播。

- **问题四（固定点约束与更新）**:
  - **确认/修复**: 固定点优先选取内部顶点（若存在）；添加硬约束时仅在内部未知集中修改矩阵行；更新 UV 时跳过固定点，避免覆盖硬约束。

- **代码修改要点**:
  - 局部阶段：改为直接计算 `J = U * X^{-1}`（见 `hw6_arap.cpp` 中局部阶段实现）。
  - 全局矩阵构建：修正为对每条半边直接读取相邻两个面的 cot（使用 face index 访问 `triangles[face_idx]`），构建对角和非对角项。
  - 全局右端项：对每个邻居累加相邻两个面中 `cot * (L_t * (x_i - x_j))`，若邻居为边界则额外加上 `cot_sum * u_j`。
  - 能量计算：使用局部二维坐标和 `J = U * X^{-1}` 计算并累加 `A_t * ||J - L_t||_F^2`，并跳过退化/无穷值情况。

## 运行调试步骤（建议）
- 重新编译并在 Ruzino 中运行该节点，观察控制台日志；本次实现已在局部/能量阶段添加统计打印（如下键词）：
  - `[ARAP][Debug] Local phase: L_identity=..., J_invalid=..., detX_min=..., detX_max=...`
  - `[ARAP][Debug] Energy: contrib=..., skipped_degX=..., skipped_invalidJ=..., skipped_nonfinite=..., det_min=..., det_max=...`
- 读取这些统计量的含义：
  - `L_identity` 很大（接近面数）→ 大量三角形回退为单位旋转，说明 `J` 或 `X` 不可逆或初始 `uv` 导致共线；检查 Floater 初始化并可视化 UV。
  - `skipped_degX` 很大 → 三角形在局部基下投影退化，可能是基向量构造错误或阈值过严（可调整 `DET_EPS`）。
  - `skipped_invalidJ` / `skipped_nonfinite` 非零 → 出现 NaN/Inf，需要追踪产生 NaN 的环节（通常是矩阵求逆或除零）。
