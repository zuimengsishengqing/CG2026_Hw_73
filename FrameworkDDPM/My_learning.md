## 二、DDPM 核心数学原理：从公式到代码的逐行映射

这是项目的基础，我们将**每一个核心公式都对应到你代码的具体实现**，彻底讲清 “公式怎么变成代码”。

### 2.1 前向扩散过程：从原始图像到纯噪声

#### 数学原理

前向扩散是一个**固定的马尔可夫链过程**，核心是对原始图像x0逐步添加高斯噪声，经过T步后，xT趋近于标准高斯噪声N(0,I)。

1. **单步扩散定义**：

   对任意时间步t，从xt−1到xt的扩散过程为：

   q(xt∣xt−1)=N(xt;1−βtxt−1,βtI)

   其中βt是**噪声调度**（你的代码中用线性调度，从 0.0001 线性增长到 0.02），控制每一步添加的噪声强度。

   

2. **闭式解推导（核心优化）**：

   直接迭代T步计算xt效率极低，利用高斯分布的可加性，可推导出**任意时间步\**t\**的\**xt\**的闭式解**，无需逐步迭代：

   q(xt∣x0)=N(xt;αˉtx0,(1−αˉt)I)

   展开为采样形式：

   xt=αˉt⋅x0+1−αˉt⋅ϵ,ϵ∼N(0,I)

   其中：

   

   - αt=1−βt：单步信号保留比例
   - αˉt=∏s=1tαs：累积信号保留比例（从t=1到t的αs连乘）

   

#### 代码实现对应（`forward_noising.py`）

你的代码完全贴合上述公式，每一行都有明确的数学意义：

```
# 1. 定义噪声调度：对应β_t的线性增长
def linear_beta_schedule(timesteps, start=0.0001, end=0.02):
    return torch.linspace(start, end, timesteps)

# 2. 预计算所有核心参数（闭式解需要的所有项，避免训练时重复计算，核心工程优化）
T = 300
betas = linear_beta_schedule(timesteps=T)
alphas = 1.0 - betas                          # 对应α_t = 1-β_t
alphas_cumprod = torch.cumprod(alphas, axis=0) # 对应ᾱ_t = ∏α_s（累积连乘）
sqrt_alphas_cumprod = torch.sqrt(alphas_cumprod) # 对应√ᾱ_t
sqrt_one_minus_alphas_cumprod = torch.sqrt(1.0 - alphas_cumprod) # 对应√(1-ᾱ_t)

# 3. 前向加噪核心函数：完全对应闭式解公式
def forward_diffusion_sample(x_0, time_step, device="cpu"):
    # 生成标准高斯噪声ε ~ N(0,I)
    noise = torch.randn_like(x_0)
    
    # 从预计算参数中取出当前时间步t的√ᾱ_t和√(1-ᾱ_t)
    sqrt_alphas_cumprod_t = get_index_from_list(sqrt_alphas_cumprod, time_step, x_0.shape)
    sqrt_one_minus_alphas_cumprod_t = get_index_from_list(sqrt_one_minus_alphas_cumprod, time_step, x_0.shape)
    
    # 完全对应闭式解：x_t = √ᾱ_t·x_0 + √(1-ᾱ_t)·ε
    mean = sqrt_alphas_cumprod_t.to(device) * x_0.to(device)
    variance = sqrt_one_minus_alphas_cumprod_t.to(device) * noise.to(device)
    
    return mean + variance, noise
```

**值得学习的细节**：

- `get_index_from_list`函数：解决了批次维度的匹配问题，让不同样本的不同时间步能正确取出对应的参数，是批量训练的核心适配。
- 预计算所有参数：扩散过程的βt,αˉt等与输入图像无关，预计算后训练时只需查表，大幅提升训练效率。

### 2.2 逆向扩散过程：从纯噪声还原图像

#### 数学原理

逆向扩散是前向过程的逆过程，目标是从xT（纯噪声）逐步预测xT−1,xT−2,...,x0（原始图像）。核心是通过贝叶斯公式推导**后验分布\**q(xt−1∣xt,x0)\****，再用 UNet 拟合这个分布的参数。

1. **后验分布推导**：

   由贝叶斯公式q(xt−1∣xt,x0)=q(xt∣x0)q(xt∣xt−1,x0)q(xt−1∣x0)，结合高斯分布的性质，可推导出后验分布也是高斯分布：

   q(xt−1∣xt,x0)=N(xt−1;μ~t(xt,x0),β~tI)

   其中：

   

   - 后验均值：μ~t(xt,x0)=1−αˉtαˉt−1βtx0+1−αˉtαt(1−αˉt−1)xt
   - 后验方差：β~t=1−αˉt1−αˉt−1βt（固定值，无需学习）

   

2. **用预测噪声简化均值计算**：

   我们无法直接获取x0，但可以通过闭式解反推出x0=αˉt1(xt−1−αˉt⋅ϵ)，将其代入后验均值公式，可得到**仅用\**xt\**和预测噪声\**ϵθ\**就能计算的均值**：

   μθ(xt,t)=αt1(xt−1−αˉtβtϵθ(xt,t))

   这是 DDPM 最核心的简化：**只需训练 UNet 预测噪声\**ϵθ\**，就能完全确定逆向扩散的后验分布**。

   

3. **逆向采样步骤**：

   对t从T到1逐步迭代：

   xt−1=μθ(xt,t)+σt⋅z,z∼N(0,I),t>0

   当t=0时，方差为 0，无需添加噪声，直接返回均值μθ(x0,0)。

sqrt_recip_alphas = torch.sqrt(1.0 / alphas) # 对应1/√α_t
posterior_variance = betas * (1.0 - alphas_cumprod_prev) / (1.0 - alphas_cumprod) # 对应后验方差β̃_t

# 单步去噪核心函数：对应逆向采样的单步计算
@torch.no_grad()
def sample_timestep(model, x, t, class_label=None):
    # 1. UNet预测噪声ε_θ(x_t, t)，对应公式中的ϵ_θ
    predicted_noise = model(x, t, class_label)
    
    # 2. 取出当前时间步的预计算参数
    betas_t = get_index_from_list(betas, t, x.shape)
    sqrt_one_minus_alphas_cumprod_t = get_index_from_list(sqrt_one_minus_alphas_cumprod, t, x.shape)
    sqrt_recip_alphas_t = get_index_from_list(sqrt_recip_alphas, t, x.shape)
    
    # 3. 计算后验均值μ_θ，完全对应上面的均值公式
    mean = sqrt_recip_alphas_t * (x - betas_t * predicted_noise / sqrt_one_minus_alphas_cumprod_t)
    
    # 4. 取出后验方差β̃_t
    posterior_variance_t = get_index_from_list(posterior_variance, t, x.shape)
    
    # 5. t=0时无噪声，直接返回均值；t>0时添加高斯噪声
    if t[0].item() == 0: # 你之前踩过的坑：必须用.item()转标量，否则tensor比较会出错
        return torch.clamp(mean, -1.0, 1.0)
    else:
        noise = torch.randn_like(x)
        result = mean + torch.sqrt(posterior_variance_t) * noise
        return result

# 完整去噪流程：从x_T到x_0的迭代
@torch.no_grad()
def sample_plot_image(model, device, img_size, T, target_class=None):
    # 1. 初始化x_T ~ N(0,I)，纯高斯噪声
    img = torch.randn((1, 3, img_size, img_size), device=device)
    
    # 2. 从t=T-1迭代到t=1，逐步去噪
    for i in reversed(range(1, T)):
        t = torch.full((1,), i, device=device, dtype=torch.long)
        img = sample_timestep(model, img, t, class_label)
    
    # 3. 最后一步t=0，得到最终图像x_0
    t = torch.full((1,), 0, device=device, dtype=torch.long)
    img = sample_timestep(model, img, t, class_label)
    
    return img
```

**值得学习的细节**：

- `torch.no_grad()`：采样阶段无需计算梯度，大幅降低显存占用，提升速度。
- `clamp`仅在 t=0 时使用：中间步骤 clamp 会破坏噪声分布，导致生成图像偏灰，这是你之前踩过的核心坑，也是扩散模型采样的关键技巧。
- 时间步的范围控制：DDPM 的时间步是[0,T−1]，代码中严格遵循了这个范围，避免索引越界和分布错误。

### 2.3 训练目标：从 ELBO 到简化 MSE 损失

#### 数学原理

DDPM 的训练目标来自**变分下界（ELBO）**，通过最大化对数似然的下界，最终简化为一个极其简单的 MSE 损失。

1. **变分下界分解**：

   对数似然logpθ(x0)的变分下界为：

   logpθ(x0)≥Eq(x1:T∣x0)[logpθ(x0:T)−logq(x1:T∣x0)]

   进一步分解后，核心优化项是**相邻时间步的 KL 散度**，最终可简化为：

   L=Et,x0,ϵ[∥ϵ−ϵθ(xt,t)∥2]

   其中ϵ是前向扩散中添加的真实噪声，ϵθ(xt,t)是 UNet 预测的噪声。

   

2. **简化的核心意义**：

   原本复杂的变分推断问题，被简化为 **“预测噪声与真实噪声的均方误差”**，训练目标极其简单，稳定性远超 GAN 等生成模型，这是 DDPM 最核心的创新之一。

    predicted_noise = model(x_noisy, t, class_label)
    
    # 3. 计算MSE损失：||ε - ε_θ||²
    loss = F.mse_loss(noise, predicted_noise)

- 类别标签的传入：为文生图的条件生成做了适配，训练时让模型学习 “类别→噪声分布” 的映射。

## 三、UNet 网络结构：设计逻辑与数学意义

DDPM 的噪声预测网络必须满足两个核心需求：**捕捉图像的多尺度特征**、**融入时间步 / 类别条件信息**，你的 UNet 设计完全贴合这两个需求，每一部分都有明确的数学和工程意义。

### 3.1 为什么选择 UNet？

扩散过程中，不同时间步的噪声对应不同的图像频率：

- 大t（高噪声）：噪声覆盖全局，需要捕捉图像的低维语义特征（下采样）；
- 小t（低噪声）：噪声集中在细节，需要还原图像的高分辨率纹理（上采样 + 跳跃连接）。

UNet 的**编码器 - 解码器结构 + 跳跃连接**，完美适配这个需求：

- 编码器（下采样）：逐步压缩特征图，提取全局语义信息；
- 解码器（上采样）：逐步恢复分辨率，还原细节纹理；
- 跳跃连接：将编码器的同分辨率特征直接拼接到解码器，解决上采样过程中的细节丢失问题，这是扩散模型生成清晰图像的关键。

### 3.2 核心模块的设计逻辑

#### 1. 正弦位置嵌入（SinusoidalPositionEmbeddings）

**数学意义**：将离散的时间步t（0~T-1）映射为连续的高维向量，让模型能区分不同时间步的噪声分布，本质是**为时间步添加位置编码**，和 Transformer 的正弦位置编码原理完全一致。

公式：

PEt,2i=sin(t/100002i/d)

PEt,2i+1=cos(t/100002i/d)

其中d是嵌入维度（你的代码中是 32），i是维度索引。

**代码实现**：`unet.py`中的`SinusoidalPositionEmbeddings`类，完全复现了上述公式，将标量时间步转换为高维嵌入向量。

#### 2. Block 模块：条件融合与特征提取

Block 是 UNet 的基础单元，核心设计是**将时间 / 类别条件嵌入融合到卷积特征中**：

1. 先通过两次卷积 + GroupNorm+ReLU 提取特征；
2. 将时间嵌入（+ 类别嵌入）通过全连接层映射到和特征图相同的通道数，扩展维度后直接加到特征图上；
3. 最后通过卷积完成上 / 下采样。

**关键设计：GroupNorm 替代 BatchNorm**

这是你之前踩过的核心坑，也是扩散模型的标准设计，原因是：

- BatchNorm 依赖批次的统计量（均值、方差），而你的 batch_size=1 时，统计量完全无意义；
- 扩散模型的输入分布随时间步剧烈变化，BatchNorm 的滑动平均统计量无法适配这种分布变化；
- GroupNorm 在通道维度做归一化，不依赖批次大小，完全适配小 batch 和分布变化的场景，是扩散模型的最优选择。

#### 3. 类别嵌入：文生图的条件适配

你为文生图添加的`class_emb`层，数学意义是**将类别条件编码为高维向量，和时间嵌入融合后，让模型学习条件生成的分布\**p(x∣c)\****。

实现逻辑：

1. 用`nn.Embedding(2, 32)`将 0/1 的类别标量映射为 32 维向量，和时间嵌入维度对齐；
2. 前向传播时，将类别嵌入和时间嵌入相加，融合后传入 Block 模块；
3. 训练时模型学习 “不同类别对应不同的噪声分布”，采样时指定类别，就能生成对应类别的图像。

## 四、RePaint 图像补全：项目最具深度的创新点

这部分是项目的拔高内容，完全贴合 RePaint 论文的核心思想，**无需重新训练模型，仅通过修改采样流程就能实现任意掩码的图像补全**，是扩散模型 “生成先验复用” 的经典案例。

### 4.1 RePaint 的核心数学思想

传统图像补全方法需要针对掩码分布重新训练模型，泛化性极差。RePaint 的核心创新是：**利用预训练 DDPM 的无条件生成先验，在逆向采样过程中，通过掩码约束已知区域，让未知区域的生成与已知区域自然融合**。

数学上，RePaint 的核心是对逆向采样的每一步，做**已知区域和未知区域的解耦处理**：

1. **已知区域（掩码 mask=0）**：不使用模型的预测结果，而是用原始图像x0前向扩散到t−1步的结果，保证已知区域的内容完全符合原始图像；
2. **未知区域（掩码 mask=1）**：使用 DDPM 模型的逆向采样结果，让模型基于生成先验补全内容；
3. **合并结果**：用掩码加权合并两个区域的结果，作为下一步的输入。

对应论文中的核心公式：

xt−1known∼N(αˉtx0,(1−αˉt)I)(8a)

xt−1unknown∼N(μθ(xt,t),σt2I)(8b)

xt−1=m⊙xt−1unknown+(1−m)⊙xt−1known(8c)

其中m是掩码（1 = 补全区域，0 = 保留区域），⊙是逐元素相乘。

### 4.2 重采样（Resampling）的数学意义

直接用上述公式合并，会出现**已知区域和未知区域纹理 / 语义不和谐**的问题，论文中通过**重采样机制**解决这个问题。

**核心逻辑**：每一步逆向采样后，不是直接进入下一个时间步，而是先向前扩散 jump_length 步，再重新逆向扩散回来，让已知区域和未知区域的信息充分融合，解决边界不和谐的问题。

数学意义：通过多次 “前向 - 逆向” 的循环，让模型在每一个时间步都能充分学习已知区域的语义和纹理信息，让补全的内容和原始图像在全局上保持一致，而不是仅在局部匹配。

        for u in range(jump_n_sample):
            # 3.1 未知区域：模型逆向采样一步，对应公式8b
            img_denoised = sample_timestep(model, img, t_tensor, class_label)
            
            # 3.2 已知区域：原始图像前向扩散到t-1步，对应公式8a
            t_minus_1_tensor = torch.full((1,), t - 1, device=device, dtype=torch.long)
            img_known_noisy, _ = forward_diffusion_sample(original_img, t_minus_1_tensor, device)
            
            # 3.3 掩码合并，对应公式8c
            img = mask * img_denoised + (1 - mask) * img_known_noisy
            
            # 3.4 重采样：前向扩散jump_length步，对应论文算法1的第9-10步
            if u < jump_n_sample - 1:
                jump_steps = min(jump_length, t - 1)
                if jump_steps > 0:
                    for _ in range(jump_steps):
                        t_jump = torch.full((1,), t, device=device, dtype=torch.long)
                        img, _ = forward_diffusion_sample(img, t_jump, device)
    
    # 4. 最后一步t=0，得到最终补全图像
    t_zero = torch.full((1,), 0, device=device, dtype=torch.long)
    img = sample_timestep(model, img, t_zero, class_label)
    
    return img
```

#### 1. 整体架构（对应`unet.py`的`SimpleUnet`）

plaintext











```
输入图像 x_t (3×64×64)
    ↓
[初始卷积] 3→64通道
    ↓
┌─────────────────────────────────────┐
│  编码器（下采样路径）：提取全局语义  │

┌─────────────────────────────────────┐
│  解码器（上采样路径）：还原细节纹理  │
│  Block 1024→512 + 拼接跳跃连接4    │
│  Block 512→256 + 拼接跳跃连接3     │
│  Block 256→128 + 拼接跳跃连接2     │

    ↓

#### 2. 核心模块：Block（对应`unet.py`的`Block`类）

Block 是 UNet 的基本单元，**同时完成特征提取和条件信息融合**：

plaintext











```
输入特征图 + 时间/类别嵌入向量
    ↓
[卷积1] + [GroupNorm] + [ReLU] → 提取特征

##### 🎉 你的理解完全正确！补充 2 个深度细节

1. 为什么不重采样效果不好？

   

   直接用掩码合并已知区域和未知区域，会出现 **“边界断层”**：

   - 已知区域是用原始图像前向扩散的，保留了真实的纹理和语义；
   - 未知区域是用模型预测的，是基于生成先验的；
   - 两者在边界处的 “噪声模式” 不匹配，直接合并会导致边界模糊、纹理不连贯、语义不一致（比如论文中提到的 “狗的毛补全成了模糊的纹理，而不是完整的狗耳朵”）。

   

2. 重采样的本质是 “让信息充分流动”

   ：

   

   重采样的 “正向加噪→逆向去噪” 循环，本质是

   让已知区域的信息 “扩散” 到未知区域，同时让未知区域的生成先验 “适配” 已知区域

   ：

   - 正向加噪时，已知区域的真实信息会 “污染” 未知区域，让未知区域也带上已知区域的特征；
   - 逆向去噪时，模型会基于 “混合了已知区域特征的噪声”，重新预测未知区域，让生成的内容和已知区域更和谐；
   - 多次重采样后，边界处的信息完全融合，全局一致性大幅提升。

   

3. 关于 “质量对比” 的补充

   ：

   - 不是 “重采样后比直接生成质量高”，而是 “**重采样后补全区域和已知区域的和谐度更高**”；
   - 直接生成是无条件的，可能生成质量很高的图像，但和已知区域完全不相关；

### 1. 训练阶段为什么随机采样时间步？

### 你的理解

> 不应该从 0 ~ T-1 都均匀进行过预测吗？还是说训练次数足够多 5000 次的话相对平均进行过采样了

##### ✅ 你的理解完全正确！补充 2 个深度原因

1. **随机采样 ≈ 均匀覆盖（大数定律）**：

   你说得对，虽然单次是随机的，但训练 5000 个 epoch、每个 epoch 有多个 batch 的情况下，**0~T-1 的每一个时间步都会被采样到非常多次**，在统计意义上是 “均匀覆盖” 的。

   

   - 数学上，这是**蒙特卡洛近似**：用随机采样的期望来近似真实的均匀期望；
   - 工程上，这比 “强制按顺序遍历 0~T-1” 更高效，因为不需要额外的调度逻辑。

   

2. **为什么不按顺序遍历？**

   按顺序遍历（比如每个 batch 固定用 t=0,1,2...）会导致**模型过拟合到时间步的顺序**，而不是学习到 “任意时间步的噪声预测”。随机采样能让模型更鲁棒，泛化性更好。

### 2. 参数预计算，噪声随机生成

### 你的理解

> 对于参数我现在理解是预计算好的，但基于参数会随机生成噪声

##### ✅ 完全正确！再帮你把逻辑链理得更顺

完整的前向加噪逻辑链是：

1. 预计算固定参数

   （和输入图像、训练过程完全无关）：

   - 先定义噪声调度 βt（线性从 0.0001 到 0.02）；
   - 再计算 αt=1−βt、αˉt=∏s=1tαs、αˉt、1−αˉt；
   - 这些参数存在内存里，训练时直接查表。

   

2. 训练时动态随机生成

   （和输入图像、时间步相关）：

   - 对每个 batch，随机采样时间步 t；
   - 随机生成噪声 ϵ∼N(0,I)（形状和图像一致，RGB 三个通道独立采样）；
   - 用预计算的参数和随机噪声，计算加噪图像 xt=αˉt⋅x0+1−αˉt⋅ϵ。

### 3. 生成多样性的噪声是 “比较小的量”

### 你的理解

> 保证生成过程多样性是训练时候加上的一个被参数约束的比较小的量吧，太大了影响图片生成质量

##### ✅ 核心正确，补充 2 个关键细节

1. **采样时的噪声方差是 “时间步自适应” 的，不是固定的 “小量”**：

   你代码中采样时添加的噪声方差是**预计算的后验方差 \**β~t\****，它是随时间步变化的：

   

   - 大 t（比如 t=299）：β~t 比较大（接近 0.02），添加的噪声多，保证多样性；

   - 小 t（比如 t=10）：β~t 非常小（接近 0.0001），添加的噪声少，保证生成质量；

   - t=0

     ：

     β~t=0

     ，不添加噪声，直接输出最终图像。

     

     这个设计非常巧妙：

     大 t 时靠噪声保证多样性，小 t 时靠确定性保证质量

     。

   

2. **“多样性” 和 “训练时的噪声” 无关，只和 “采样时的噪声” 有关**：

   训练时的噪声是 “真实噪声”，用来让模型学习预测；

   采样时的噪声是 “生成噪声”，用来让每次生成的图像不一样（多样性）。

### 5.上 / 下采样卷积的区别，以及和高低噪声的关系

### 你的问题

> 上 / 下采样卷积有什么区别？具体是怎么卷积的？如何做到你说的高低噪声？

##### 📚 详细讲解（结合你的代码）

这是一个非常核心的工程细节，我会结合你代码中的参数来讲：

#### 1. 下采样卷积（编码器用，降低分辨率，提取全局特征）

你的代码中，下采样 Block 的 transform 是：



```
self.transform = nn.Conv2d(out_ch, out_ch, 4, 2, 1)
```

参数解析：

- `in_channels=out_ch`：输入通道数
- `out_channels=out_ch`：输出通道数
- `kernel_size=4`：卷积核大小 4×4
- `stride=2`：步长 2（每次移动 2 个像素）
- `padding=1`：填充 1 个像素

**具体怎么卷积的？**

- 输入特征图尺寸：H×W
- 输出特征图尺寸：2H+2×1−4+1=2H×2W（分辨率减半）
- 效果：用 4×4 的卷积核 “看” 更大的区域，压缩分辨率，提取**全局语义特征**（比如 “这是一只猫”）。

#### 2. 上采样卷积（解码器用，恢复分辨率，还原细节）

你的代码中，上采样 Block 的 transform 是：

python



运行









```
self.transform = nn.ConvTranspose2d(out_ch, out_ch, 4, 2, 1)
```

参数解析：

- `ConvTranspose2d`：转置卷积（也叫反卷积），是下采样卷积的 “逆操作”
- `kernel_size=4`、`stride=2`、`padding=1`：和下采样卷积的参数完全对应

**具体怎么卷积的？**

- 输入特征图尺寸：H×W
- 输出特征图尺寸：(H−1)×2−2×1+4=2H×2W（分辨率翻倍）
- 效果：将低分辨率特征图 “放大” 回高分辨率，结合跳跃连接的细节，还原**高分辨率纹理**（比如 “猫的胡须”）。

#### 3. 怎么和 “高低噪声” 对应？

这是一个非常巧妙的设计：

- 大 **t**（高噪声）

  ：

  

  图像经过多次下采样，分辨率很低（比如 64×64→4×4），特征是 “全局语义”，模型靠这些特征预测 “大尺度的噪声”（比如 “整体的颜色分布”）；

- 小 **t**（低噪声）

  ：

  

  图像经过多次上采样，分辨率恢复到 64×64，结合跳跃连接的原始细节，模型靠这些特征预测 “小尺度的噪声”（比如 “边缘的纹理”）。

### 6. 0/1 标量怎么映射到 32 维向量？

### 你的问题

> 0/1 的类别标量（形状 [1]）映射为 32 维的高维向量（形状 [1, 32]）是怎么映射的值？全 0 和全 1 的区别吗？

##### ❌ 纠正：不是全 0 / 全 1，是 “可学习的向量”

这是一个非常容易误解的点，我详细讲`nn.Embedding`的原理：

#### 1. `nn.Embedding`的本质：一个可学习的查找表

你的代码中：

```
self.class_emb = nn.Embedding(num_classes, time_emb_dim)
# num_classes=2, time_emb_dim=32
```

它的本质是**一个形状为 [2, 32] 的可学习矩阵**，初始化时是随机的（比如正态分布初始化），不是全 0 / 全 1。

#### 2. 具体怎么映射？

- 输入类别标量 `0`：从矩阵中取第 0 行，得到形状 [32] 的向量；
- 输入类别标量 `1`：从矩阵中取第 1 行，得到形状 [32] 的向量；
- 再扩展维度，得到形状 [1, 32] 的向量，和时间嵌入对齐。

#### 3. 训练时怎么更新？

这个 [2, 32] 的矩阵是**可训练的参数**，会随着梯度下降一起更新：

- 训练时，输入 “类别 0 的图像 + 类别 0 的向量”，模型会调整第 0 行的向量，让它更能代表 “类别 0 的特征”；
- 输入 “类别 1 的图像 + 类别 1 的向量”，模型会调整第 1 行的向量，让它更能代表 “类别 1 的特征”；
- 最终，第 0 行和第 1 行的向量会变得 “不一样”，分别对应两个类别的噪声模式。
