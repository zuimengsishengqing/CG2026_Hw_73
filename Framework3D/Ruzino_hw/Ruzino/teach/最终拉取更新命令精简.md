完整操作步骤（复制粘贴直接执行）
1. 进入你的 Ruzino 根目录
cmd
cd "F:\CG2026\homework in winter\USTC_CG_26\Framework3D\Ruzino_hw\Ruzino"
2. 获取远程最新提交（绝对安全，不修改任何本地文件）
cmd
git fetch origin main
3. 先预览所有即将下载的新增文件（确认无误再执行下一步）
cmd
git diff --name-only --diff-filter=A HEAD origin/main
输出的就是远程有、但你本地完全没有的所有文件
如果输出为空，说明你本地已经是最新版本，无需更新
4. 一键下载所有新增文件（核心命令）
cmd
for /f "delims=" %f in ('git diff --name-only --diff-filter=A HEAD origin/main') do git checkout --no-overlay origin/main -- "%f"
执行结果说明
绝对不覆盖任何已有文件：
你修改过的代码文件：完全保留你的修改
你删除过的文件：不会被恢复
你未跟踪的文件：完全不受影响
自动创建所有必要的文件夹：如果新增文件在新的子目录中，会自动创建对应的文件夹
新增文件状态：所有下载的文件会显示为Untracked（未跟踪）状态，你可以根据需要决定是否添加到 Git
验证更新结果
执行完后立即执行：
cmd
git status
你会看到：
你之前所有的修改（modified:、deleted:）完全没有变化
你之前所有的未跟踪文件完全没有变化
只会在Untracked files部分新增本次下载的文件
只更新特定目录（可选）
如果你只想更新作业相关的source/Editor/geometry_nodes目录，不下载其他无关文件，执行这个命令：
cmd
for /f "delims=" %f in ('git diff --name-only --diff-filter=A HEAD origin/main -- source/Editor/geometry_nodes/') do git checkout --no-overlay origin/main -- "%f"
